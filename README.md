
# Churn Prediction with XGBoost

## Contexte
Projet de Data Science visant à prédire le churn bancaire (clients qui quittent).

## Technologies
- Python
- Pandas
- XGBoost

## Algorithmes testés
- Logistic Regression → Recall ~37%
- Random Forest → Recall ~43%
- XGBoost (optimisé) → Recall ~65%

## Résultats
- Accuracy : 82.8%
- Recall (classe churn) : 65%
- F1-score : 0.60

## Fichiers
- `Untitled35.ipynb` → code complet
- `churn_predictions.csv` → résultats client par client
